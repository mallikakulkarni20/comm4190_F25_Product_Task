# comm4190_F25_Product_Task: Jacket Design A/B Project

This project explores two concept jackets that integrate a jetpack feature and temperature control technology
It includes creative brainstorming files, generated assets, and A/B testing results comparing **Product A (JetJacket)** and **Product B (Levium)**.

---

## A/B Testing Results
Across all four user segments we tested, **Levium (Product B)** consistently outperformed JetJacket (Product A), earning higher ratings (7–9 vs. 5–7) and unanimous preference. The test users chose Levium for its more refined and user-centric features (personal climate zones, carbon-fiber exoskeleton, solar power integration, and foldable portability). It was also perceived as more comfortable and travel-ready, therefore appealing to both younger professionals and older travelers.

Some explanations for why users prefered Levium were:
- "JetJacket highlights a sleek, modern design. However, Levium's feature set, including voice-activated commands and a heads-up display, presents a more futuristic, tech-oriented style that aligns well with urban and travel settings."
- "The Levium jacket provides a more balanced feature set for everyday use, focusing on accessible, real-world applications while maintaining innovative functions."
- "Both jackets offer active temperature control, but Levium's use of smart materials and personal climate zones for targeted thermal regulation suggests a more refined approach to maintaining optimal warmth and comfort."

Therefore, the winner was Levium, for its balance of advanced technology, comfort, and versatility.

## File Descriptions

### **Folders**
- **`logos_a/`** — Logo concepts generated for **Product A (JetJacket)**.  
- **`logos_b/`** — Logo concepts generated for **Product B (Levium)**.  
- **`photos_a/`** — Photorealistic product mockups generated for **Product A (JetJacket)**.  
- **`photos_b/`** — Photorealistic product mockups generated for **Product B (Levium)**.  

### **Notebooks**
- **`A_B_test.ipynb`** — Contains the A/B testing process comparing JetJacket and Levium.  
  This notebook includes participant responses, product comparisons, and results analysis.  
- **`brainstorm_a.ipynb`** — Brainstorming notebook for **Product A (JetJacket)**.  
  Includes name ideas, slogans, product descriptions, logo prompts, and photo generations.  
- **`brainstorm_b.ipynb`** — Brainstorming notebook for **Product B (Levium)**.  
  Follows the same structure as *brainstorm_a* but explores alternative directions.  

### **Markdown Files**
- **`productA.md`** — Final product website content for **JetJacket**.  
- **`productB.md`** — Final product website content for **Levium**.
